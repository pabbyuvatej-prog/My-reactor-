# QUARK STABILIZER — Concept Infrastructure

This is a fictional/sci-fi machine design package for the AV project.
It is a visual/concept specification, not a real particle-physics device.

Contents:
- design/assembly.json — conceptual component hierarchy and dimensions
- design/blueprint.svg — simple schematic blueprint
- design/materials.json — fictional material/component labels
- docs/design_notes.md — concept notes and safety boundary
- viewer/index.html — lightweight browser viewer for the SVG blueprint

The "quark stabilizer" terminology here refers to the user's fictional technology universe.
